# opac009

This repo contains the results and prompting transcipts for an autonomous solution to [OPAC-009](https://realopacblog.wordpress.com/2019/09/22/the-schur-cone-and-the-cone-of-log-concavity/), which in turn is based on conjectures of [White](https://arxiv.org/abs/0903.2831).

The solution and initial writeup were done entirely by Claude (Fable-5.1), with minimal human prompting and direction (see transcript). The bulk of the work was done in about three hours over September 8-9, 2026.  A second round of refereeing was done by ChatGPT-6 (Astra), along with some simplifications in the proof and improvements to the exposition; this is the final version presented as `opac009-solution.{tex,pdf}`.

Supplementary code is stored in the supplements folder.
